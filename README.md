# Duracreto MarketView

App web instalable (PWA) de inteligencia de mercado y ventas de Duracreto: Mapa de mercado, Mis proyectos, Estudio de precios y Dashboard.
Se publica con GitHub Pages. Los datos viven en Google Sheets y se leen a través de un servidor de Apps Script (`config.js` → `API_URL`).
Este repositorio no contiene contraseñas ni datos.
